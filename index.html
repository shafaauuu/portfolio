Harry Potter Film Characters Face Recognition

Using deep learning, particularly CNNs like AlexNet, and image augmentation, the model shows flexibility in overcoming challenges. The project focuses on classification and quality assessment using two deep learning methods. Image augmentation expands the dataset to prevent accuracy drop at epoch 5. Visual tools like the F1, PR, P, R curves, and Confusion Matrix enhance model dynamics. Roboflow further supports its practical application.

Tools: Python, PyTorch, YOLOv5, Roboflow, TensorFlow.
