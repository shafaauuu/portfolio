# Shafira Aulia Yasmin's Portfolio

A modern, responsive portfolio website showcasing my projects, skills, and experience in AI, web development, and software engineering.

## Features

- Responsive design that works on all devices
- Interactive portfolio with category filtering
- Animated elements using CSS and JavaScript
- Typed.js for dynamic text animation
- Smooth scrolling and navigation
- Project showcase with detailed modals
- Skills section with animated badges
- Contact section with social media links
- Modern UI with clean design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Font Awesome
- Google Fonts
- Typed.js

## Project Structure

```
portfolio/
├── css/
│   ├── styles.css (Bootstrap core styles)
│   └── custom.css (Custom styles)
├── js/
│   ├── scripts.js (Core JavaScript)
│   └── custom.js (Custom JavaScript)
├── images/
│   └── (Project images and profile picture)
└── index.html (Main HTML file)
```

## Getting Started

1. Clone the repository
2. Open `index.html` in your browser
3. Explore the portfolio!

## Customization

- Update the content in `index.html` to reflect your personal information
- Modify styles in `custom.css` to change colors, fonts, and layout
- Add your own projects to the portfolio section
- Update the skills section with your own skills
